Bitácora Táctica de Resolución

Registro secuencial de los problemas abordados y las soluciones de ingeniería aplicadas.

V

Colapso PostCSS (Viernes)

Problema: El servidor Vite colapsó en el arranque indicando Cannot find module 'autoprefixer'. Tailwind v4 había cambiado su arquitectura de dependencias.
Solución: Intervención manual en la terminal para forzar la instalación de los motores secundarios mediante npm install -D autoprefixer y eliminación de archivos de configuración obsoletos de la v3.

S

Pantalla Blanca de la Muerte (Sábado)

Problema: Fatal Runtime Error. React esperaba recibir un Array limpio ["baloto", "boyaca"] pero el backend envió un objeto anidado complejo. La iteración falló provocando el apagado total de la interfaz.
Solución: Implementación del patrón "Cascarón Blindado". Inyección de un script de telemetría para leer el JSON crudo, y construcción de un algoritmo de Auto-Búsqueda que extrae dinámicamente arrays ocultos dentro de objetos para prevenir colapsos.

D

Bloqueo de Seguridad Ngrok (Domingo)

Problema: Al establecer el túnel público Ngrok para la presentación, el servidor Vite detectó un host desconocido y bloqueó el acceso devolviendo Blocked request por motivos de seguridad CORS.
Solución: Configuración granular en vite.config.ts inyectando la propiedad allowedHosts con dominios comodín para autorizar la entrada de tráfico mundial a través del túnel.
