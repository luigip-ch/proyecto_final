La Metáfora del Restaurante

Para entender la arquitectura de nuestra aplicación, dividimos el sistema en tres partes:

La Cocina (Backend)

FastAPI + Python + IA. Aquí se procesan los datos matemáticos. Puerto 9002.

El Mesero (API)

El archivo JSON que transporta el pedido de la mesa a la cocina.

El Comedor (Frontend)

React + Tailwind v4. Donde el usuario interactúa visualmente. Puerto 5173.

Hito 1: El Puente de Red (Proxy)

Teníamos un problema de seguridad: los navegadores bloquean peticiones entre puertos diferentes (CORS). Resolvimos esto configurando Vite para que actuara como un intermediario encubierto. 

// vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:9002', // Direccionamos en secreto a la cocina
        changeOrigin: true,
      }
    }
  }
})

Hito 2: La Pantalla Blanca de la Muerte (Blindaje)

Al principio, cuando la "Cocina" mandaba un error o un formato de datos inesperado, React colapsaba mostrando una pantalla en blanco. Construimos un algoritmo de "Auto-descubrimiento" que evita que la app muera. 

// App.tsx - Sistema Anti-Colapso
const data = await response.json();

// Si el dato es un Objeto, buscamos dinámicamente dónde está la lista adentro
if (data && typeof data === 'object') {
    const listInObj = Object.values(data).find(val => Array.isArray(val));
    setLotteries(listInObj); // ¡Salvados de la pantalla en blanco!
}

Hito 3: Visualización de Impacto (UI/UX)

En lugar de mostrar el resultado en texto crudo, decodificamos el JSON y renderizamos esferas CSS dinámicas. Si un modelo falla (ej. arrojando solo 2 balotas), la UI lo atrapa con elegancia sin romperse.
