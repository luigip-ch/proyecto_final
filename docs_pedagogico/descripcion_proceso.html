La Crónica del Baloto

Una historia de 48 horas: De una carpeta vacía a una plataforma de IA de nivel corporativo.

01. El Punto de Partida

El viernes comenzó con una pantalla en blanco y una sensación de incertidumbre. Teníamos los datos, pero no el "vehículo" para mostrarlos. Esta sección describe cómo decidimos dividir el fin de semana para conquistar cada obstáculo técnico sin perder el enfoque en el diseño.

Distribución del Esfuerzo Diario

1

Viernes: Cimentación. Instalamos React, Vite y Tailwind. Resolvimos el primer choque de dependencias.

2

Sábado: Conexión. Creamos el "puente" (proxy) para que el frontend hablara con la IA.

3

Domingo: Pulido. Renderizamos las balotas y abrimos el túnel público con Ngrok.
